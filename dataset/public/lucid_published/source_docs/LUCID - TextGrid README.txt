LUCID - README.txt

The TextGrids available for DiapixUK conversations have been merged together. Speaker A (whose speech underwent degradation in the vocoded, babble and L2 conditions) and Speaker B (conversation pair and listener) TextGrid tiers have been labeled, except in the case of the L2 TextGrids, which contain only one tier with Speaker A's (the native speaker of British English) speech transcribed.

The merged TextGrids have filenames that mirror the corresponding stereo file. The L2 TextGrids follow with the same file-naming convention but contain only one TextGrid tier. The L2 TextGrids have been re-named from an expanded filename with "_Nuc" appended at the end (normalized, unchecked) to the current format (e.g., M41CM2F2clL22_Nuc.TextGrid uploaded as M41CM2F2clL22.TextGrid).
